# Sistema de Controle de Estoque (Java)

Sistema de gerenciamento de inventário desenvolvido em Java puro como parte de projetos práticos de engenharia de software. A aplicação implementa um CRUD completo gerenciado via console, aplicando conceitos fundamentais de Orientação a Objetos e estruturas de dados em memória.

## Funcionalidades
* **Cadastro de Produtos:** Adição de novos itens informando ID, nome, categoria, preço e quantidade em estoque.
* **Listagem:** Visualização formatada de todos os produtos cadastrados no sistema.
* **Atualização (Update):** Modificação dinâmica do nome, categoria, preço ou quantidade de produtos existentes buscando pelo ID.
* **Exclusão (Delete):** Remoção segura de itens do estoque com base no ID.
* **Interface Interativa:** Menu dinâmico via console com validações de fluxo (`do-while` e `Scanner`).

## Tecnologias Utilizadas
* **Java** (JDK 21)
* Programação Orientada a Objetos (POO) - Encapsulamento, Classes e Métodos
* Estruturas de Dados (`ArrayList`)
* Tratamento de fluxo e entrada de dados
